# To-Do List

A minimal to-do list in plain HTML, CSS and JavaScript. No frameworks, no build step.

## Features

- Add a todo by typing and pressing Enter.
- Left-click a todo to mark it completed or active.
- Right-click a todo to delete it.
- Todos persist between visits using the browser's `localStorage`.

## Run it

Open `index.html` in any modern browser, or serve the folder with a static server:

```bash
npx serve .
```

## Files

| File | Purpose |
|---|---|
| `index.html` | Page structure |
| `style.css` | Styling |
| `script.js` | Add, toggle, delete and persist todos |

## Notes

Data is stored only in your browser. Clearing site data removes your todos.
